# spiderbox.cn 结构逆向笔记（原创仿站依据）

> 分析目标：只提取**信息架构与交互模式**，不复制对方文案、图标、Logo、链接清单。
> 本地 REA（`D:\soft\pythonProject\rea`）因 Node 版本不满足 `^22.23.4 || ^24.22.1 || >=26.12.1`（当前 v24.17.0）未能直接跑 CLI；本笔记结合页面 DOM / 公开内容完成。

## 站点类型

资源导航站（Link Directory）：左侧锚点导航 + 右侧分区块卡片列表。

## 顶层导航（一级）

- 最新文章/视频
- 常用推荐
- 文档资料
- 通用工具
- WEB / 安卓 / iOS / 小程序相关
- 人机验证、代理数据、交流学习
- AI 逆向、AI 其他
- GitHub、提交收录

## 通用工具下的二级模式（样例）

实用工具、抓包工具、接口调试、管理调度、虚拟账号、库/包、效率插件、Hook/调试、混淆/反混淆、设备指纹、TLS 指纹、环境框架、指纹浏览器、自动化/RPA、AI 自动化 等。

## UI 特征

- 背景浅灰 `rgb(249,249,249)`，正文深色
- 左侧固定分类树，点击 hash 锚点滚动到对应区块
- 区块标题 + 多列工具卡片（图标/标题/短描述/外链）
- 顶部常有「最新内容」信息流

## 可复用到 AI 工具站的模式

1. 一级：对话 / 绘画 / 视频 / 编程 Agent / MCP / 知识库 / 语音 / 自动化 / 学习资料  
2. 二级：按用途再分（如编程 Agent → IDE 插件、CLI、云端）  
3. 搜索过滤卡片；本地 JSON 维护收录，避免硬编码爬对方数据
